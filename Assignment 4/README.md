📌 About This Assignment

This assignment explores the fundamentals of file handling in Python. It focuses on reading text files, writing and appending data, and handling errors using exception handling.

🎯 Tasks Overview

📂 Task 4.1 — Read a File & Handle Errors

Objective: Read the contents of sample.txt and handle missing-file errors gracefully.

Requirements

* 📖 Open and read sample.txt.
* 📝 Display the file content line by line.
* 🛡️ Handle FileNotFoundError if the file does not exist.

Key Concepts: open(), readline(), try-except, FileNotFoundError

✍️ Task 4.2 — Write & Append Data to a File

Objective: Take user input, save it to output.txt, append additional data, and display the final content.

Requirements

* ⌨️ Take text input from the user.
* 💾 Write the input to output.txt.
* ➕ Append additional data to the same file.
* 📄 Read and display the final file content.

Key Concepts: input(), write(), file modes (w, a, r), with open()
