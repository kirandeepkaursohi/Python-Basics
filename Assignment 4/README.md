Assignment 4: Python File Handling

Overview

This assignment covers basic file handling operations in Python, including reading files, writing data, appending content, and handling errors gracefully.

Task 4.1: Read a File and Handle Errors

Problem Statement

Write a Python program that:

* Opens and reads a text file named sample.txt.
* Prints its content line by line.
* Handles errors gracefully if the file does not exist.

Concepts Covered

* File opening and reading using open()
* Reading files line by line
* Exception handling using try-except
* Handling FileNotFoundError

Expected Behavior

The program displays the contents of sample.txt line by line. If the file does not exist, it displays an appropriate error message instead of terminating unexpectedly.

Task 4.2: Write and Append Data to a File

Problem Statement

Write a Python program that:

* Takes user input and writes it to a file named output.txt.
* Appends additional data to the same file.
* Reads and displays the final content of the file.

Concepts Covered

* Taking user input using input()
* Writing data using write mode ("w")
* Appending data using append mode ("a")
* Reading data using read mode ("r")
* Using file handlers and the with statement

Expected Behavior

The program asks the user to enter text, writes it to output.txt, and then asks for additional text to append. Finally, it displays the complete contents of the file.

Technologies Used

* Programming Language: Python 3
* Editor: Any Python-compatible code editor
* Version Control: Git and GitHub

How to Run

1. Clone or download this repository.
2. Open the Assignment 4 folder in your code editor.
3. Ensure sample.txt exists in the appropriate directory before running Task 4.1.
4. Run the Python files using the terminal:

python task4_1.py
python task4_2.py



Note: output.txt will be generated automatically when Task 4.2 runs.

Learning Outcomes

After completing this assignment, I can:

* Read and process text files in Python.
* Write and append data to files.
* Handle missing-file errors using exception handling.
* Understand different file access modes.
* Use file handling techniques to manage data efficiently.
